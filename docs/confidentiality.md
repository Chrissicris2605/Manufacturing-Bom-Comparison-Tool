# Confidentiality notice

This repository is a public portfolio demo and was rebuilt from scratch with generic rules and fictional data.

It does not contain:

- production source code;
- proprietary algorithms;
- real engineering files;
- company data;
- client data;
- internal naming conventions;
- confidential business logic;
- screenshots from private systems.

The project exists only to demonstrate engineering automation skills in a safe, educational, and portfolio-friendly way.

## Naming choices

The demo uses the generic term `code` as the item identifier to avoid exposing terminology from any specific organization, industry workflow, or internal implementation.

## Data choices

All sample records are fictional and intentionally small. They are only meant to show how the comparison workflow behaves.
