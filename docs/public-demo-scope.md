# Public demo scope

This project is intentionally small and generic.

## Included

- CSV loading and validation
- Item comparison by `code`
- Status classification: Added, Removed, Modified, Unchanged
- Excel report generation with summary and color-coded rows
- Simple desktop interface for selecting files and generating the report
- Fictional sample data

## Not included

- Production business rules
- Real company templates
- Private file formats
- Advanced matching logic
- Internal review workflows
- Company-specific terminology
- Any data from professional environments

## Future improvements

Potential public improvements may include:

- drag-and-drop file selection;
- richer report formatting;
- optional column mapping;
- support for `.xlsx` input files;
- automated tests;
- a packaged Windows executable for demonstration.
